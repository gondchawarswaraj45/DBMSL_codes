College Event Management System
Problem Statement:
Design an application to manage college events. The system should allow students to register for
events, manage event schedules, and track participation and certificates.
Conceptual Design (ER Elements):  Entities: Student, Event, Organizer, Venue, Certificate
Relationships:
-> A Student can register for many Events
-> An Organizer manages multiple Events
-> An Event is conducted at one Venue
-> A Certificate is issued to a Student for participating in an Event
